Bienvenido a GestApp

Desde esta aplicación podrás administrar los empleados y departamentos de forma sencilla y rápida.

Utiliza el menú superior para acceder a las distintas opciones disponibles:

  • Consultar el listado de empleados/departamentos/usuarios
  • Crear nuevos empleados/departamentos
  • Editar o eliminar empleados/departamentos existentes

Si no le aparecen las opciones, procúrese de:

  • Iniciar sesión
  • Registrar
  • Tener suficiente privilegio
