Bienvenido a Aplicacion Ventas

Desde esta aplicacion podras administrar los clientes y pedidos de forma sencilla y rapida.

Utiliza el menu superior para acceder a las distintas opciones disponibles:

  • Consultar el listado de clientes/pedidos/usuarios
  • Crear nuevos clientes/pedidos
  • Editar o eliminar clientes/pedidos existentes

Si no le aparecen las opciones, procurese de:

  • Iniciar sesion
  • Registrar
  • Tener suficiente privilegio
